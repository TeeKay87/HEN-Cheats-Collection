# Frequently Asked Questions

## What is HEN Cheats Collection?

HEN Cheats Collection is an independent project created, curated and maintained by TeeKay87. The website organizes the curated collection by game, Title ID, version, format, creator and source file so visitors can find and inspect entries without manually browsing the repository structure.

## Is HENCC affiliated with Sony?

No. HEN Cheats Collection is an independent project created, curated and maintained by TeeKay87 and is not affiliated with, endorsed by, sponsored by or operated by Sony Interactive Entertainment. PlayStation, game titles, trademarks and artwork belong to their respective owners.

## Why does the Title ID matter?

The same game name can exist under more than one PlayStation Title ID. HENCC treats the full ID as part of the entry's identity, so a similarly named game under another CUSA/PPSA ID should not automatically be considered equivalent.

## Why does the game version matter?

Cheats can depend on the layout of a specific game update. A source listed under one version is therefore not assumed to work on another version. HENCC keeps versions separate and gives each game/version its own direct route.

## What do CUSA and PPSA mean on this website?

HENCC uses `CUSA` identifiers as PlayStation 4 entries and `PPSA` identifiers as PlayStation 5 entries for platform presentation and filtering. The complete identifier—not just the prefix—is what distinguishes the catalog entry.

## Why are there several files for one game/version?

Different creators may have separate sources, several formats may exist, or the files may contain different cheat sets. HENCC keeps those physical sources separate so attribution, Notes, Issue state and row lists remain attached to the correct file.

## What are JSON, MC4 and SHN?

They are the source-file format labels represented by HENCC. The format helps identify which kind of source file you are looking at, but format alone does not determine compatibility. Title ID, version and the individual source still matter.

## What does the Issue warning mean?

An Issue warning means that source has been marked as having a reported problem. The warning is source-specific and is deliberately shown so visitors can take it into account before using or reporting the file.

## What are Notes?

Notes are optional source-specific Markdown content stored with a source's website metadata. When present, HENCC renders them above the source's cheat rows to provide additional context.

## What does “Downloaded” mean?

Downloaded is a local browser marker. When HENCC initiates a source download, it records that source in LocalStorage for the current browser profile. It is not an online account history and does not prove that the source was successfully used.

## How do Favorites work?

Favorites are also stored locally in the browser. The heart button adds or removes a game ID from the local Favorites set. Using another browser/device or clearing site storage can therefore change which Favorites are available.

## Why did a game or file disappear from the catalog?

HENCC website metadata can hide an entire game or an individual source file. Hidden content is intentionally excluded from the normal catalog and from the static crawlable output. An entry can also disappear when the underlying collection changes.

## How are creators credited?

Creator names are attached to the source files represented by the exported metadata. HENCC displays those names on the relevant source. The collection does not present itself as the author of cheats created by the listed creators.

## What if Added or Updated shows a dash?

Those dates come from optional public date maps. A dash means that HENCC does not currently have a date recorded for that game/version in the corresponding map. The source files can still be present and valid collection entries.

## Does HENCC guarantee every cheat works?

No. Presence in the catalog is not a guarantee of universal compatibility. Title ID, version, source-specific requirements and combinations of cheats can matter. HENCC exposes Notes and Issue metadata so known context can be shown rather than hidden.

## How do I report a problem?

Open the game/version, expand the affected source and use its Report Issue action. The generated GitHub issue includes identifying information for the game, version and source so TeeKay87 can tell exactly which file you mean.

## Does HENCC explain how to jailbreak a PS4 or PS5?

No. HENCC's public website documentation focuses on the collection, its metadata, file formats, Title IDs, game versions and troubleshooting collection entries. It does not provide jailbreak instructions or links to jailbreak tutorials.
