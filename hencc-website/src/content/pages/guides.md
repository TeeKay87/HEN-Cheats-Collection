# HENCC Guides

HEN Cheats Collection contains more than a list of filenames. The catalog exposes Title IDs, versions, formats, creators, source files, notes, issue states and cheat rows because those details help visitors choose the entry they actually intended to use.

The guides below explain that information and the website features around it. They focus on **using and understanding HENCC itself**. They do not provide instructions for bypassing console security or for jailbreaking PlayStation hardware.

## Getting Started

[Getting Started with HEN Cheats Collection](/guides/getting-started/) explains the normal website workflow: searching the catalog, opening a game, choosing a version, inspecting individual source files, downloading a file, saving Favorites and reporting a problem.

Use this guide if you are not sure what the different controls or metadata on the website mean.

## Cheat File Formats

[Cheat File Formats in HENCC](/guides/file-formats/) explains the JSON, MC4 and SHN labels shown on cards, version tabs and source files. It also explains why the same game/version can have several files instead of one universal download.

Use this guide when you understand which game/version you need but are unsure why multiple formats or sources are listed.

## Title IDs and Game Versions

[Title IDs and Game Versions](/guides/title-ids-and-versions/) explains the CUSA and PPSA identifiers used in the catalog, how version matching works, and why two entries with the same game title are not automatically interchangeable.

This is the most important compatibility guide in the documentation.

## Troubleshooting

[Troubleshooting HENCC Entries](/guides/troubleshooting/) provides a structured checklist for cases where a source does not appear to match what you expected. It covers Title ID, version, format, process metadata, conflicting cheats, Issue flags, Notes and problem reporting.

## Frequently Asked Questions

The [FAQ](/faq/) answers shorter recurring questions about creators, Favorites, Downloaded markers, hidden entries, source files and how the collection is curated.
