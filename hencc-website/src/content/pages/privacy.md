# Privacy Policy

**Last updated: August 23, 2026**

This page describes the privacy-relevant behavior of the HEN Cheats Collection website. HENCC is an independent project created, curated and maintained by TeeKay87 and does not provide user accounts on this website.

## Local browser storage

HENCC uses the browser's LocalStorage for features that are intended to remain available between visits on the same browser profile.

### Favorites

The Favorites feature stores a list of favorited game IDs locally in your browser under the HENCC website origin. This information is used to show your Favorites view and heart state. It is not synchronized to an HENCC account or server-side profile.

### Downloaded markers

When the website initiates a cheat-file download, it stores a local marker for that source file so the interface can display that it has previously been downloaded from that browser profile. This marker is local UI state; it is not a record that the file was successfully used.

You can remove this local state using your browser's site-data/storage controls. Clearing browser storage can reset Favorites and Downloaded markers.

## Vercel hosting and performance services

The website is hosted on Vercel. The application also includes **Vercel Web Analytics** and **Vercel Speed Insights** components. These services can process technical request, usage and performance information according to Vercel's own service behavior and privacy terms.

HENCC uses these integrations to understand website traffic and performance rather than to create user accounts or personalized HENCC profiles.

## Google AdSense

The website includes Google AdSense publisher configuration and the Google AdSense script. Advertising may not be active at all times. When Google advertising is enabled and served, Google and its advertising partners may use cookies, local storage or similar technologies for advertising, measurement, fraud prevention and related purposes according to Google's policies and the consent choices applicable to the visitor.

HENCC does not control the data practices of Google or other third-party advertising providers. For visitors in regions where Google requires consent management for personalized advertising, production ad serving must use a Google-certified Consent Management Platform (CMP) integrated with the IAB Transparency and Consent Framework (TCF). HENCC's intended production configuration is Google's AdSense Privacy & messaging CMP. The website source cannot by itself prove that the account-side message is enabled, so that setting must be verified in the AdSense account before a new review or applicable ad serving.


## Consent choices for advertising

When the configured Google-certified CMP is active, visitors in applicable regions can be shown the consent choices provided by that CMP before personalized advertising is served. Those choices and any consent records created by the CMP are handled through the CMP/Google advertising system rather than through an HENCC user account.

HENCC's own Favorites and Downloaded markers are first-party interface preferences and are separate from advertising-consent state. The website does not use those HENCC LocalStorage values to personalize advertising.

## External images and resources

Game cover images can be loaded from external image hosts referenced by HENCC cover metadata. Loading an external image can cause the visitor's browser to make a request directly to that host, which can expose ordinary request information such as IP address, user agent and referrer behavior according to the browser and host.

The site can also link to external services such as GitHub. Following an external link leaves HENCC and makes the destination service's own privacy policy applicable.

## Cheat-file downloads

Cheat-file download links are built from the source path stored by HENCC and point to the HEN Cheats Collection repository/download host. When you download a file, your browser communicates with that external hosting service to retrieve it.

HENCC's local Downloaded marker does not contain the contents of the downloaded file and is not uploaded as an HENCC user history.

## Report Issue links

The Report Issue action opens GitHub with a pre-filled issue template for the selected game/version/source. No issue is submitted merely by opening the link. If you choose to submit the issue, the information you submit is handled by GitHub and becomes subject to GitHub's account/privacy behavior and the visibility of the repository's issue tracker.

Review the issue text before submitting it and avoid including personal information that is not necessary to describe the collection problem.

## No HENCC user accounts

The website does not currently provide HENCC login accounts, profiles, private messaging or cloud synchronization for Favorites/Downloaded state. The site features documented above operate either from public collection data, local browser storage or third-party services.

## Children and sensitive personal information

HENCC is not designed to request sensitive personal information from visitors. Do not include passwords, private account credentials, precise private addresses or other sensitive personal information in public GitHub issue reports.

## Changes to this policy

This policy should be updated when the website's actual storage, analytics, advertising, consent or third-party integrations change. The implementation is the source of truth: the policy is intended to describe what the site actually does, not to list hypothetical tracking technologies.
