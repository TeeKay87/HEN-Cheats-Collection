# Contact HEN Cheats Collection

HEN Cheats Collection is an independent project created, curated and maintained by **TeeKay87**. The best contact path depends on what you need to report.

## Report a problem with a cheat source

For a problem tied to a specific game/version/source file, use the **Report Issue** action inside that source's expanded detail view. HENCC generates a GitHub issue with the game ID, version and source identification already included.

That workflow is preferred because it reduces ambiguity and links the report back to the exact collection entry.

## General collection issues

For a broader collection or website issue that is not tied to one source, use the HEN Cheats Collection repository's issue tracker:

[Open the HEN Cheats Collection issue tracker](https://github.com/TeeKay87/HEN-Cheats-Collection/issues)

Please describe the affected page, game ID or behavior as precisely as possible.

## Attribution or creator-credit questions

If creator attribution appears missing, duplicated or incorrect, open an issue and identify the exact game, version and source filename. Creator metadata is source-specific, so the exact file matters when correcting attribution.

## Copyright or takedown requests

If you are a rights holder or authorized representative and believe material presented through HENCC should be removed or changed, use the public issue/contact path above and clearly identify the specific material and your request. Do not publish sensitive personal information in a public issue; if a private follow-up is needed, state that in the initial request without posting confidential details.
