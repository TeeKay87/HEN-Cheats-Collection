# About HEN Cheats Collection

HEN Cheats Collection is an independent project created, curated and maintained by TeeKay87. The project exists to make a large, constantly changing collection easier to browse than a raw repository tree. Instead of making visitors search through folders and filenames, HENCC organizes available data by game, Title ID, version, file format and creator, then presents it through one searchable interface.

The website is built around a simple idea: **finding the right entry should be easier than finding the right file manually**. A game can have several regional Title IDs, several update versions and several source files created by different people. HENCC keeps those pieces visible so visitors can compare them before downloading anything.

## What the collection contains

The public catalog currently focuses on PlayStation 4 and PlayStation 5 cheat files represented in the collection's supported JSON, MC4 and SHN formats. A single game/version can contain one source file or several. Each visible source keeps its own metadata, including its format, process, creator list, row count, optional notes and issue state when that information is available.

The website does not merge every source into one anonymous result. Creator attribution is kept at source-file level because two files for the same game and version can come from different authors and can contain different sets of cheats.

## How the collection is organized

Every game is primarily identified by its **Title ID**. PlayStation 4 entries normally use a `CUSA` identifier and PlayStation 5 entries normally use a `PPSA` identifier. Versions are stored separately under each Title ID because a cheat created for one game update is not automatically compatible with another update.

The catalog therefore treats the combination of Title ID and version as important information rather than decorative metadata. The website's direct links follow that same model, so an individual version can be shared without losing the ID/version context.

## How HENCC is curated

The collection is personally curated and maintained by TeeKay87 rather than being an automatically published scrape. Collection data is generated from the curated source set and then exported into the public website data used by the catalog.

The website supports metadata that helps keep unsuitable or uncertain entries out of the normal public view. Games and individual source files can be hidden when they should not be presented in the catalog. A source can also carry an **Issue** flag when a known problem should be made visible to visitors, and **Notes** can provide source-specific context directly above the cheat rows.

These fields are part of the public presentation model: they exist so the website can communicate the state of a source instead of treating every file as equally verified or equally suitable for every visitor.

## Creators and attribution

HENCC is a collection, not a claim of authorship over the cheats it catalogs. Source files retain the creators listed in HENCC metadata, and the website shows those creators alongside the corresponding files. Where several creators are listed for one source, HENCC preserves that source-level attribution.

If attribution appears to be missing or incorrect, the project can be contacted through the options on the [Contact page](/contact/).

## What HENCC does not guarantee

A file being present in the collection does not mean it will work with every game release, every update, every environment or every combination of enabled cheats. Title ID and version matching matter, individual sources may have different requirements, and some files may later be marked with an Issue when a problem is reported.

For that reason, HENCC presents compatibility-oriented metadata rather than promising universal compatibility. The [Title IDs and Game Versions guide](/guides/title-ids-and-versions/) explains the matching model, and the [Troubleshooting guide](/guides/troubleshooting/) covers the checks that are useful when an entry does not behave as expected.
